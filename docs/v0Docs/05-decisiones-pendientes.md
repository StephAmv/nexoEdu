# Decisiones pendientes

Antes de iniciar el desarrollo técnico conviene confirmar las siguientes decisiones.

## Acceso y usuarios

- ¿Los alumnos tendrán cuenta propia desde la primera versión?
- ¿Se permitirá que un usuario tenga más de un rol?
- ¿Quién podrá crear usuarios: dirección, administrador del sistema o ambos?
- ¿Se requerirá recuperación de contraseña por correo electrónico desde la primera versión?

## Plataforma

- ¿El sistema será solo una plataforma web responsiva?
- ¿Se requiere aplicación móvil nativa?
- ¿Se desarrollará como PWA para permitir notificaciones push?

## Notificaciones

- ¿Qué canales de notificación se usarán al inicio?
- ¿Se enviarán notificaciones por correo electrónico?
- ¿Se enviarán notificaciones dentro del sistema?
- ¿Se enviarán notificaciones push?

## Pagos y comprobantes

- ¿Los pagos se registrarán manualmente?
- ¿Se integrará una pasarela de pago?
- ¿Los comprobantes tendrán validez fiscal o serán recibos internos?
- ¿Se manejarán becas, descuentos y recargos desde la primera versión?

## Conducta, asistencia y permisos

- ¿Qué información disciplinaria podrá ver directamente el alumno?
- ¿Qué información disciplinaria solo podrá ver el padre/tutor?
- ¿Qué personal puede validar justificantes?
- ¿Qué personal puede autorizar permisos de salida?
- ¿Las faltas justificadas deben afectar reportes de asistencia de forma distinta?

## Dirección y administración

- ¿Dirección podrá editar información o solo consultarla y autorizarla?
- ¿Administración podrá ver información académica o disciplinaria?
- ¿Qué reportes son indispensables para la primera versión?

## Datos y seguridad

- ¿Cuánto tiempo se conservarán las evidencias y archivos adjuntos?
- ¿Se requiere respaldo automático diario?
- ¿Quién podrá consultar la bitácora completa?
- ¿Qué datos personales serán obligatorios para alumnos y tutores?
