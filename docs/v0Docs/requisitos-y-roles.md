# Requisitos y roles del sistema escolar

Este documento queda como punto de entrada para la documentación de requisitos. La información detallada se dividió en documentos específicos para mantener una base más clara, ordenada y fácil de mantener.

## Lectura recomendada

1. [`00-resumen-ejecutivo.md`](00-resumen-ejecutivo.md): visión general del sistema, alcance, actores y primera versión recomendada.
2. [`01-requisitos-funcionales.md`](01-requisitos-funcionales.md): detalle de módulos y funcionalidades esperadas.
3. [`02-roles-y-permisos.md`](02-roles-y-permisos.md): definición de roles y matriz inicial de permisos.
4. [`03-entidades-y-reglas.md`](03-entidades-y-reglas.md): reglas generales, entidades sugeridas y requisitos no funcionales.
5. [`04-roadmap.md`](04-roadmap.md): fases recomendadas de desarrollo.
6. [`05-decisiones-pendientes.md`](05-decisiones-pendientes.md): preguntas por resolver antes o durante el diseño técnico.

## Objetivo resumido

Crear una plataforma integral para una escuela que centralice alumnos, docentes, padres/tutores, asistencia, conducta, comunicación, calificaciones, pagos, inventario de uniformes, reportes y auditoría.

## Base recomendada para iniciar

La primera fase debe enfocarse en autenticación, roles, alumnos, tutores, docentes, grupos, asistencia, reportes de conducta, evidencias, visualización para padres/tutores y bitácora básica.
